# Orizon Benefits — Site institucional

Protótipo estático responsivo em HTML/CSS/JS.

## Abrir
Abra `index.html` no navegador.

## Publicação
Pode ser publicado diretamente em Netlify, Vercel, GitHub Pages ou hospedagem tradicional.

## Antes de produção
- Substituir o logo em CSS pelo SVG/PNG oficial da Orizon Benefits.
- Definir telefone, e-mail, LinkedIn, CNPJ e informações regulatórias corretas.
- Integrar o formulário ao CRM, e-mail ou WhatsApp.
- Criar páginas de Política de Privacidade/LGPD.
- Substituir quaisquer dados ilustrativos do dashboard por dados aprovados.
- Inserir logos de operadoras apenas quando houver autorização para uso.
